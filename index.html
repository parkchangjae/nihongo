개인 학습 설정

API 키와 GitHub 토큰은 이 브라우저의 로컬 저장소에만 저장됩니다. 코드나 Gist 백업 파일에는 포함하지 않습니다.

Google AI Studio에서 발급한 키를 입력하세요.
기본값은 현재 연결 테스트에서 사용한 모델입니다. 계정에서 사용할 수 있는 모델명으로 변경할 수 있습니다.
Gist 권한만 부여한 토큰을 권장합니다. 만료일을 설정하세요.
Gist 주소가 https://gist.github.com/계정/여기ID 라면 마지막 부분만 입력합니다.
주의: 브라우저에 저장한 API 키와 토큰은 이 기기의 브라우저 데이터에 접근할 수 있는 사람이나 악성 스크립트에 노출될 수 있습니다. 공용 기기에서는 사용하지 마세요. Secret Gist도 완전한 비밀 저장소는 아닙니다. Gemini 무료 등급의 데이터 처리 조건도 확인하고 민감한 개인정보는 입력하지 마세요.
